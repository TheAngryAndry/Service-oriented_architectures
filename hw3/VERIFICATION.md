# Проверка ДЗ 3

Дата: 4 ноября 2026. Среда: Linux x86_64, Rust 1.95.0, Docker Compose 5.4.0.

**20 автоматических тестов прошли, ошибок нет.**

| Набор | Результат |
| --- | --- |
| Unit: выбор retry-кодов, одиночная HALF_OPEN-проба, защита от позднего ответа | 3/3 |
| gRPC с управляемыми сбоями: 3 попытки, backoff, бизнес-ошибки, одинаковый booking_id, дедлайн, восстановление circuit | 5/5 |
| E2E: REST → gRPC → отдельные PostgreSQL + настоящий Redis Cluster | 9/9 |
| Реальные отключения контейнеров: Flight, все Redis, один мастер с повышением реплики | 3/3 |

E2E проверил:

- создание, чтение, список и идемпотентную отмену брони;
- неизменность сохранённой стоимости после изменения цены рейса;
- отсутствие брони при нехватке мест и некорректных данных;
- 20 параллельных запросов на последнее место: одна успешная бронь;
- 10 одновременных ReserveSeats с одним booking_id: один резерв;
- отсутствие/неверный API key на всех пяти gRPC-методах;
- TTL, попадание в кэш и инвалидизацию после резервирования, отмены и UpdateFlight;
- ограничения PostgreSQL и запрет бронирования неактивного рейса;
- компенсацию после успешного резерва и принудительной ошибки записи Booking;
- восстановление осиротевшего резерва и незавершённой отмены.

При отключённом Flight API возвращал 503, открытый circuit отвечал без сетевого
ожидания; собственные бронирования оставались доступны. После запуска Flight
состояние восстановилось через HALF_OPEN.

При остановке всех шести Redis бронирования продолжались через PostgreSQL.
После восстановления кэша возвращались актуальные остатки. Отдельно подтверждено
автоматическое повышение реплики при отказе одного мастера. Bootstrap ожидает
не только cluster_state:ok, но и завершения синхронизации всех реплик.

Команды:

```sh
cargo fmt --check
cargo clippy --locked --all-targets --all-features -- -D warnings
docker compose -f docker-compose.yml config --quiet
docker compose --profile test run --build --rm tests
DOCKER_SUDO=1 cargo test --locked --features fault-tests --test faults -- --ignored --test-threads=1 --nocapture
```

Docker-образы собраны из исходников с `--locked`; миграции применились автоматически.
После проверок контейнеры восстановлены.

На тестовом хосте из-за его VPN использован локальный override Docker-сети.
Он не входит в репозиторий; опубликованный Compose создаёт собственную сеть.
Код сервисов, образы, базы, конфигурация Redis и volumes в проверках соответствуют
опубликованному решению. Это проверка поведения системы, не измерение промышленной нагрузки.
